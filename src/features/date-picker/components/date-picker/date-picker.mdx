# DatePicker

A fully customizable React date picker with single & range selection, time
picking, CSS token theming, rich tooltips, slot overrides, and full event
support. It ships zero-dependency beyond React and
[dayjs](https://day.js.org/).

---

## Installation

```bash
npm install flexy-date-picker
```

Import the CSS once in your app entry file:

```ts
import 'flexy-date-picker/styles';
```

---

## Quick start

```tsx
import { DatePicker } from 'flexy-date-picker';

function App() {
  return (
    <DatePicker
      placeholder="Select date"
      onDateChange={(d) => console.log(d?.format('YYYY-MM-DD'))}
    />
  );
}
```

## Selection modes

### Single (default)

Click any day to select a single date. `onDateChange` is called with a
`dayjs` object (or `null` on clear).

<Canvas of={DatePickerStories.Default} />

### Range

Set `mode="range"` to enable two-step selection: first click sets the
**start** date, second click sets the **end** date.
`onRangeChange` receives `{ start, end }`.

## Disabled dates

The `disabled` prop accepts:

| Shape | Behaviour |
|-------|-----------|
| `true` | Disable every date |
| `{ before }` | Disable dates before the given dayjs |
| `{ after }` | Disable dates after the given dayjs |
| `{ dates }` | Disable a specific list of dayjs values |
| `{ predicate }` | Disable any date where the function returns `true` |

All shapes can be combined in a single object.
